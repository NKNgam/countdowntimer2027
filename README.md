# Countdown Timer: March 30, 2027

A modern, high-precision, responsive countdown timer web application built with vanilla JavaScript, CSS3, and HTML5.

🌐 **Live Demo**: [https://nkngam.github.io/countdowntimer2027/](https://nkngam.github.io/countdowntimer2027/)

## Features
- **Real-time Live Ticking**: Accurate down to the millisecond, calculating days, hours, minutes, and seconds.
- **Progress Tracking**: Visual progress bar showing elapsed percentage between start date and March 30, 2027.
- **Total Metrics Breakdown**: Live calculations of total days, total hours, total minutes, and total seconds remaining.
- **Dark & Light Modes**: Seamless theme switching with ambient background glow effects.
- **Web Audio Chime**: Synthesized audio chime alert (zero external dependencies).
- **Interactive Customizer**: Ability to change title, target date, or time.
- **Shareable URLs**: URL parameter support (`?target=...&title=...`) to share any countdown state.
- **Celebration Confetti**: Built-in canvas particle physics when the target date is reached.

## Getting Started

You can open `index.html` directly in any modern web browser:

```powershell
Start-Process "index.html"
```

Or run a lightweight local static server using Python or Node.js:

```powershell
# Python 3
python -m http.server 3000
```
Then visit `http://localhost:3000`.
